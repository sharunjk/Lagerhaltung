Zebra TC21 / Smartphone als Scanner-App einrichten

Einmal pro Gerät, etwa 5 Minuten. Das Gerät muss im Firmen-WLAN sein (gleiches Netz wie dieser PC). Ausführliche Anleitung mit Bildschirm-Hinweisen: Dokument „Zebra TC21 einrichten“.

  1. Sicherheitszertifikat installieren (damit die App ohne Warnung über https läuft): Auf dem Gerät in Chrome {{ zert_url }} öffnen (oder QR-Code „Zertifikat“ scannen). Chrome warnt beim ersten Mal „Verbindung nicht privat“ – Erweitert → Weiter zu {{ ip }} tippen, die Datei wird heruntergeladen. Dann Einstellungen → Sicherheit → Verschlüsselung & Anmeldedaten → Zertifikat installieren → CA-Zertifikat → „Trotzdem installieren“ → Datei Lagerverwaltung-CA.crt wählen.
  2. App öffnen: In Chrome {{ app_url }} aufrufen (oder QR-Code rechts scannen) und anmelden.
  3. Installieren: Auf der Startseite „App installieren“ tippen bzw. Chrome-Menü ⋮ → „App installieren“ / „Zum Startbildschirm hinzufügen“. Die Lagerverwaltung erscheint als eigenes Symbol, startet ohne Adressleiste und funktioniert auch offline.
  4. Scantaste (nur Zebra): App DataWedge → Profil anlegen „Lager“ → Zugeordnete Apps: Chrome (com.android.chrome, alle Aktivitäten) → Barcode-Eingang an → Tastatureingabe (Keystroke output) an → Basisdatenformatierung: „ENTER-Taste senden“ an. Intent-Ausgabe aus.

Zertifikat nicht installierbar (z. B. gesperrtes Firmengerät)? Dann bitte die IT, das Zertifikat über die Geräteverwaltung zu verteilen. Es gilt nur für interne Adressen dieses PCs und kann keine anderen Webseiten beglaubigen.{% if cfg.server.http_nur_lokal %} Unverschlüsseltes http ist aus Sicherheitsgründen nur am Lager-PC selbst erreichbar.{% endif %}
